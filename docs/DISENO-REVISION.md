# Revisión: una mesa de archivo familiar

El usuario pidió sustituir la apariencia de menú/restaurante por papel rasgado y permitir información libre por persona. El énfasis pasa de un libro ceremonial a un archivo que se usa y se anota.

Paleta: tela azul gris `#303F46`, tinta `#263D49`, papel de algodón `#FAF7EF`, canto de papel `#D9CEB5`, sello rojo `#994F48`, lápiz `#687785`. Naranja conserva el significado de vínculo pendiente; no es un adorno.

Tipografía: Cormorant Garamond para nombres, Source Sans 3 para controles y lectura. Las notas marginales usan la cursiva de la familia existente, sin añadir descargas remotas.

Composición: navegación horizontal sobre tela, encabezado breve y dos hojas independientes: árbol ancho y expediente de persona. Bordes irregulares, textura discreta y cinta sujetando el expediente dan profundidad. Directorio como fichas de archivo y fuentes como documentos conservados. El contenido se alinea a la izquierda; los nombres de nodos se centran.

```
Entre ramas     Árbol  Personas  Documentos  Investigación
Archivo de familia                         + Persona
Inventario: personas / menciones pendientes de identificar
╱ Papel del árbol, bordes rasgados ╲  ╱ Expediente personal ╲
| Buscar y recorrer ramas         |  | Nombre / identidad  |
|                                |  | Campos / Familia    |
╲________________________________╱  | Salud, Trabajo, ... |
                                    ╲____________________╱
```

Autocrítica antes de construir: conservar el lateral verde y los medallones botánicos repetiría el problema. Se retiran. La textura no debe sustituir contraste ni obstaculizar formularios. El borde rasgado es el gesto principal; sin sellos grandes, madera fotográfica ni adornos en cada control. Las ilustraciones se construyen con CSS/SVG propios; la imagen aportada es una referencia, no una textura para copiar.

Los campos propios están visibles en la ficha y en un editor amplio. Admiten secciones libres, tipos y opciones propias, notas, fecha de observación y procedencia opcional. Se pueden editar, archivar y restaurar. «Salud» es un atajo vacío, nunca un diagnóstico inferido.
